# 🟩 Wordle

A recreation of the popular **Wordle** word-guessing game. The player has a limited number of attempts to identify a hidden five-letter word using feedback from each guess.

## 🎮 Gameplay

Try to guess the hidden five-letter word within **six attempts**.

After each guess, the game provides feedback:

* 🟩 **Green** — The letter is correct and in the correct position.
* 🟨 **Yellow** — The letter is in the word but in the wrong position.
* ⬜ **Gray** — The letter is not in the word.

Use the feedback from each guess to narrow down the possible answers.

## 🕹️ Controls

Enter a five-letter word using the keyboard and submit your guess.

| Key         | Action          |
| ----------- | --------------- |
| `A-Z`       | Enter a letter  |
| `ENTER`     | Submit guess    |
| `BACKSPACE` | Delete a letter |
